# Regional Resource Distribution

Resources should have regional identities.

Do not distribute every crafting material uniformly across the world.

The player should have reasons to travel.

Examples:

```text
The Caves
→ common ores

Golden Desert
→ rare minerals

Crimson Forest
→ blood/dark materials

Ice Mountain
→ cold-region resources

Apexia
→ manufactured components

Riptide
→ imported/stolen/high-tier goods
```

Resource tables must remain configurable and moddable.
