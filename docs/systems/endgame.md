# Endgame Activity Design

Activity specifications: [The Arena](arena.md), [Shrines](shrines.md), [Elemental Trials](elemental-trials.md), [Trial of Cataclysm](cataclysm.md), [Honor of the King](honor-of-the-king.md), and [Abyss](abyss.md).

## Endgame Philosophy

Endgame content should test different dimensions of character progression.

Current endgame activities have intentionally different purposes:

```text
The Arena
→ martial progression and sequential combat mastery
```

```text
Knight Shrines
→ advanced elemental magic
```

```text
The Kings
→ extremely rare and unique Nodes
```

```text
Elemental Trials
→ element acquisition and awakening
```

```text
Trial of Cataclysm
→ campaign boss endurance / resource preservation
```

```text
Honor of the King
→ simultaneous high-end encounter / Excalibur
```

```text
Abyss
→ effectively unlimited build stress test
```

Endgame activities should not all collapse into the same loop with different enemy statistics.
