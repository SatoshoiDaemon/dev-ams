# Inventory

## Inventory Philosophy

Inventory is partially limited rather than universally slot-limited.

Ordinary low-value or common monster drops should generally NOT consume restrictive inventory capacity.

The purpose is to avoid unnecessary inventory micromanagement for trivial objects.

More meaningful categories may have limits.

Examples include:

- equipped weapons
- combat-ready weapons
- valuable resources
- quick-use items
- currency handling where relevant
- special equipment

Inventory restrictions should exist because they create gameplay decisions, not simply because inventory systems traditionally have capacity limits.
