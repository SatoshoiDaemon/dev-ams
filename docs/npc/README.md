# NPC Documentation

This directory is reserved for dedicated NPC and faction design documents. The initial source documents do not define a standalone NPC system or complete named-character specifications.

Existing NPC-related requirements remain with their owning systems:

- [Regions](../world/regions.md): regional inhabitants, services, Fairy Forest hostility, and campaign changes.
- [World state](../world/state-and-persistence.md): persistent regional and faction changes.
- [Companions and mounts](../systems/companions.md): companion behavior and progression.
- [Basic lore](../world/lore.md): the provisional summoning premise.

Add separate English Markdown documents here when NPC or faction behavior is specified. Preserve stable IDs and keep unresolved mechanics explicit.
